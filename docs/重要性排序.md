已完成所有代码文件的整理工作，按照重要性排序分别创建了以下文件：

1. 核心架构文件 - 包含应用入口、数据库管理和路由配置
   
   - main.dart - 应用入口和主题配置
   - db_helper.dart - 单例数据库管理

2. 数据模型与状态管理文件 - 包含数据结构和状态管理逻辑
   
   - task_model.dart - 抽象任务基类
   - todo_model.dart - 待办事项数据模型
   - countdown_model.dart - 倒计时任务模型
   - todo_provider.dart - 待办事项状态管理
   - countdown_provider.dart - 倒计时任务状态管理
   - theme_provider.dart - 应用主题管理
3. 用户界面层文件 - 包含主要页面UI
   
   - countdown_screen.dart - 倒计时任务管理界面
   - todo_list_screen.dart - 待办事项管理界面
   - settings_screen.dart - 应用设置界面
4. 工具与辅助功能文件 - 包含辅助工具和同步功能
   
   - db_helper.dart - 数据库操作工具
   - sync_helper.dart - WebDAV同步功能
   - route.dart - 路由配置
5. UI组件文件 - 包含可复用的UI组件
   
   - exchange_tile.dart - 主题切换瓦片组件
